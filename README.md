# Turnos Accesibles

Trabajo Final de Metodología de Sistemas I, UTN FRGP, Grupo 28.
PWA que funciona como capa de accesibilidad sobre los sistemas públicos de turnos de salud.

## Arrancar

```bash
pnpm install
cp .env.example .env
pnpm dev
```

## Verificar

```bash
pnpm check:contrast
pnpm typecheck
pnpm test:unit
pnpm test:e2e
```
